# 🎮 Python Mini Projects Collection
## 📌 Project Overview
This repository contains a collection of Python mini-projects designed to strengthen core programming concepts such as loops, conditionals, functions, user input, and randomness.
Each task is interactive and console-based, making it ideal for beginners practicing Python fundamentals.

# 🧩 Projects Included
## 1️⃣ Riddle Game
- Displays a random riddle to the user
- Encourages logical thinking and string handling
- Uses dictionaries and random selection
## 2️⃣ Arithmetic Puzzle
- Generates random arithmetic questions
- Validates user input and checks correctness
- Strengthens math logic and conditional statements
## 3️⃣ Science Quiz
- Multiple science-based MCQ questions
- Tracks correct answers
- Implements lists of dictionaries and loops
# 4️⃣ Rock Paper Scissors (User vs Computer)
- Classic game against the computer
- Uses random choice and user input
- Demonstrates control flow and game logic
# 5️⃣ Rock Paper Scissors (Two-Player Mode)
- Two users can play interactively
- Introduces multi-player input handling
- Reinforces decision-making logic
# 🛠️ Skills & Concepts Used

- Dictionaries & Lists
- Random Module
